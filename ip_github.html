零成本上線教學

如何使用 GitHub Pages 上傳並公開這個網站

只需 5 分鐘，跟著以下互動清單執行，即可獲得免費的個人專屬網址 (`username.github.io`)！

部署步驟檢查清單 0 / 5 完成

將這整段程式碼存成電腦中的 index.html 檔案。

登入 GitHub，點擊右上角「+」-> 「New repository」，專案名稱填寫 portfolio 或 username.github.io，並設為 Public。

在 index.html 所在資料夾開啟 Terminal / Command Prompt 執行上傳指令。

進入該 Repo 的 Settings -> Pages，Build and deployment 的 Source 選擇 Deploy from a branch，Branch 選 main / root 並儲存。

約等待 1-2 分鐘重整頁面，即可看到專屬網址 https://your-username.github.io/portfolio/

bash / terminal
# 1. 初始化本地 Git 儲存庫
git init
# 2. 加入 index.html 檔案
git add .
# 3. 提交第一個 Commit
git commit -m "feat: Deploy Personal Portfolio Site"
# 4. 切換至 main 分支並關聯遠端 Repo
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
# 5. 推送至 GitHub
git push -u origin main
Git 上傳指令已成功複製到剪貼簿！
