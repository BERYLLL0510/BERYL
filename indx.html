Step-by-Step Deployment Tutorial

如何將此作品集部署至 GitHub Pages？

曾子菲您好！您可以選擇使用 **GitHub 網頁上傳** 或 **Git 終端機指令** 兩種方式，輕鬆將本頁面對外公開發布。

方法一：GitHub 網頁介面上傳 (最簡單)

推薦新手
  1. 建立 GitHub 專案庫： 登入 GitHub.com，點擊右上角「+」選取「New repository」。
  2. 專案命名： 將 Repository Name 填入 portfolio 或 zengzifei.github.io，設定為 **Public**，點擊「Create repository」。
  3. 儲存檔案： 將此段原始碼全選儲存為電腦中的 index.html。
  4. 上傳檔案： 在 GitHub 新專案頁面點選「uploading an existing file」，將 index.html 拖曳上傳，最後按下 **Commit changes**。
  5. 開啟託管： 進入專案的 Settings → 左側選單 Pages → 在 Source 選取 main 分支，按下 **Save**。

方法二：Git 終端機指令上傳

開發者指令

打開終端機 (Terminal / Git Bash)，在存放 index.html 的資料夾執行以下指令：

git init
git add index.html
git commit -m "Deploy Zeng Zi-Fei Portfolio Website"
git branch -M main
git remote add origin https://github.com/YourUsername/portfolio.git
git push -u origin main

推送完畢後，同樣前往 GitHub 專案的 Settings → Pages 設定 main 分支發布即可。
